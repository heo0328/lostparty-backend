# 문서 대응표·정리 검증

기준은 `7f7f767`의 docs 171파일이다. 이 표는 원문을 옮기기 전에 확정한 목록을 기능별 현재 문서·실제 보관 경로와 연결한다. **표의 원래 경로는 당시 식별자**이며 현재 파일 위치는 마지막 열을 사용한다.

[구성 기준](organization-plan.md) · [파일·주요 섹션 전체 대응 JSON](source-map.json) · [실행 API의 기능별 연결](api-map.json)

## 섹션·근거를 찾는 방법

JSON의 source로 원래 파일을 찾는다. 각 항목은 원문 SHA256, 현재 문서, 처리 방식, 보관 위치, 모든 주요 제목별 목적지·현재 참고, 관련 코드/테스트를 포함한다. 당시 인계·시험·후속 섹션은 원문에 보존하고 current_reference로 현재 상태를 연결한다. 현재 의미를 통합한 섹션은 가능한 경우 새 문서의 명시 앵커로 연결한다. 통계·활동 자동추가·생명주기·그룹 해산의 미결정/미완료를 완료로 바꾸지 않는다.
