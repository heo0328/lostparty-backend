# 기능 중심 문서 구성 기준

2026-10-24 사용자 승인 계획. 최초 기준은 `7f7f767`의 docs 171파일이다. [대응표](source-map.json)는 이동 전에 전체 파일·주요 제목·원문 SHA256·통합 위치·보관 위치·도구 의존을 확정한 목록이다.

## 독자와 역할

최상단 README는 방문자용 소개·주요 기능·기술·협업·개발 상태를 설명한다. 기능 문서는 현재 동작을 자체적으로 이해하게 하고, project는 현재 상태와 다음 행동을 추적한다. 원문 작업 기록은 archive에서 당시 근거로 보존한다.

## 배치 기준

상위 분류는 로그인·계정 / 원정대·캐릭터 / 레이드·주간 기록 / 그룹 / 모집·일정 / 공통 개발·운영이다. 하위도 기능별로 묶고 계약·예시·검증은 기능 곁에 둔다. 계정별 한도는 로그인·계정, 개인 완료 원장은 레이드, 파티 완료는 모집, 서버 이행은 공통 운영이 원본이다. 복합 기능은 원본 하나와 교차 링크로 설명한다.

현재 파일명은 영어 소문자·하이픈, 제목은 한국어 기능명이다. Issue 번호·작업 단계는 현재 문서 이름이 아니라 결정 근거·과거 기록에서 사용한다. OpenAPI 실행 파일명·프로필·스키마 식별자는 바꾸지 않는다. Python 도구의 기존 식별자는 경로 변경만으로 기능을 바꾸지 않는다.

## 내용 통합과 보존

기존 문서의 현재 유효한 정책·계약을 합쳐 설명하고 새 문서에는 과거 진행 순서를 복사하지 않는다. 정책 선택·대안 폐기·호환·보존 결정에 이유와 정확한 Issue 댓글/커밋을 붙인다. 당시에만 유효한 구현·인계·검증 상태는 원문과 DEV_LOG에 보존한다. 미승인·미구현·비활성 보존·Backend/Flutter/실기기 인수는 구분한다.

이동한 원문에는 보관 안내와 현재 문서 링크를 추가하고 상대 링크만 재배치한다. 변경 전 바이트는 기준 커밋과 source-map의 SHA로 확인한다. 기계 판독 JSON은 바이트를 보존하며 역사적인 내장 경로·버전·$id를 현재 자료로 재작성하지 않는다. 이를 읽는 도구·테스트·Docker 경로를 함께 변경한다.

## 실행·완료 기준

현재주·다음주 모집 관리를 시범 적용·검증·로컬 커밋한 뒤 로그인·계정 → 원정대·캐릭터 → 레이드·주간 기록 → 그룹 → 모집 나머지 → 공통 개발·운영 순서로 통합한다. 전체 대응·중요 정책·미완료 요구 보존, 상대 링크/앵커·자료/도구·Docker 경로, JSON·Python 문법·기존 계약 검증·고정 해시로 완료를 확인한다.

앱·실행 계약·DB·서버를 변경하지 않는다. 전체 기능 시험·배포·push·병합·외부 Issue 변경은 수행하지 않는다. 현재 기능 인수 상태는 공식 Issue의 최신 댓글과 NEXT_WORK를 기준으로 유지한다.
