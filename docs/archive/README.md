# 보관 문서

과거 결정과 검증 근거를 보존합니다. 보관은 기능 완료·요구 폐기·기존 API 삭제를 뜻하지 않습니다. 현재 기능 상태와 다음 담당은 [AI_CONTEXT](../project/AI_CONTEXT.md)와 [NEXT_WORK](../project/NEXT_WORK.md)를 따릅니다.

| 보관 문서 | 보관 이유·현재 기준 |
|---|---|
| [두 주차 계약 3판](recruitment/ISSUE_13_TWO_CYCLE_CONTRACT_R3.md) | 본문에 후속 4판으로 대체됐다고 명시된 구판. [4판](../features/recruitment/contracts/ISSUE_13_TWO_CYCLE_CONTRACT_R4.md)과 [공통 ACK 보완](../features/recruitment/contracts/ISSUE_13_COMMON_SETTINGS_ACK_ADDENDUM.md), 실행 OpenAPI를 함께 확인합니다. |
| [2026-10-24 정리 전 기능 지도](project/AI_CONTEXT_2026-10-24.md) | 현재 상태와 과거 진행이 섞여 있던 원문을 링크 수정과 함께 보존했습니다. 현재 지도는 [AI_CONTEXT](../project/AI_CONTEXT.md)입니다. |

다른 초안은 부분적으로 유효한 기준이나 미결정 요구를 포함하므로 기능 폴더에 유지합니다. [전체 문서 안내](../README.md).
