원문은 본문과 당시 Issue/댓글·고정 커밋 링크를 보존하고 상대 링크를 현 보관 위치에 맞췄습니다. 원래 바이트는 대응표의 기준 커밋 `7f7f767`과 SHA256으로 확인합니다. 계약·예시 JSON은 하위 기능의 examples, 당시 성능·전환 보고는 validation 또는 공통 운영 records에 내용을 바꾸지 않고 배치했습니다.
