## 2. 채택된 요구 — 구현 상태와 구분

- 개인 가능시간: 서버 회원scope 저장/새기기 복원, 요일다중/동일요일복수구간·24시간/익일종료·5분단위, 저장/취소후접힘·저장표편집. 개인표 저장은 방예약/raid주간점유가 아니다.
- 수동 방 일정: 기본미정·단일시작시각·공대장지정, 후보중하루/선택일마다 및 같은시간적용 요구를 구분한다. 미정을 now/임의 유한기간으로 바꾸지 않는다.
- 시간조율: 개인표를 방별복사하고 명시적으로다시가져오기. 해당방제출표/공통후보만공개하며 다른방/회원개인표전체는노출하지않는다.
- 현재레이드주차에서만탐색, KST수06시cyclekey유지. 설명된수10~다음수06시플레이창은주차키변경과분리검토. 출발하한은방생성서버시각+30분으로고정하며매조회시각+30분으로밀지않는다.
- 지정된추가인원이실제참가하면공대장포함참가자의현재시간점유를제외한공통구간에서가장빠른출발확정/점유. 4인방추가2설정이면총3명기준이다. 후보조회는예약이아니다.
- 먼저확정성공우선, 후보상실시기존참가유지/재조율과신규불가분기구분. 기존확정시간유지/새가입자는그시간충족. 인원미달/지각/시간경과로자동출발·연기·완료하지않는다.
- 시간변경은전원동의·승낙/거절/탈퇴3응답, 무응답동의아님. 푸시/10분응답제한은채택되지않았다.
- 신청/즉시참가는확정출발30분전마감. 생성+30분출발하한과별개다. 승인으로증가우회를허용하지않도록최종transaction검사가필요하다.
- 마지막출발가능시각은전원공통후보최후와공대장선택상한중이른조건이며확정출발시각과분리한다.
- 공통간격0/개인간격기능철회: 새개인준비간격필드/API를추가하지않는다.
- 동일레이드재도전은회차아래여러sessions/타임별참가·예약으로구분한다. 필수타임전체충족/선택타임명시참가, 클리어확정시남은재도전예약해제는채택됐다. 7타임을7개의동일raid/cycle참가·완료로만들지않는다.
- 개인완료체크의기존제품흐름(본인탈퇴/완료생성)과본인의남은예약해제를연결할설계를요청했다. 현재Backend가실제파티참가중manual완료를이미지원한다는뜻이아니다. 책임자승계/단독종료와canMark/원장을대조한다.
- 이번주미완료종료는현재방참가자누구나방전체에선언한다. 완료기록없이이번주남은타임예약과캐릭터/raid/cycle활성점유해제, 동일캐릭터의이번주동일raid다른방참가허용, 다음주함께하기구성/과거이력보존. 일반그룹원/과거참가자에게권한확대하지않고일정변경투표도요구하지않는다.
- 최소전투력은동시적용1입력/딜러·서포터개별2입력과역할별표시/실참가판정이목표다. P1을서버검증게임수치로승격하지않고신뢰·위조/null/stale/정밀도대안을설계한다.

## 3. 아직 확정 설계가 필요한 부분

- 개인가능표의시간대/주간구간정규화·최대구간/중복·익일/주차경계·보유조건/수명·CAS/멱등/원본정밀도.
- 방/레이드별항목·회차/타임·지속membership/이번주assignment·실제날짜일정/회원예약의키·수명·소유/권한, 기존단일레이드자료/API호환. 미완료종료후지속membership만으로이번주점유를재생성하지않아야한다.
- 시간조율의유한탐색범위·기간상한/클리어시까지·동시확정·후보상실·트리거가입과출발30분전마감의동일시각순서. 일괄타임조회/편집·개인응답으로왕복을억제하되현재코드만으로부하성능을보장하지않는다.
- 확정후변경안의revision/대상참가자고정·응답중가입/탈퇴·거절/무응답/동의완료시재검사와예약원자교체.
- 이번주미완료종료의현재참가자/이번주assignment자격과주차/CAS, 완료/탈퇴·새가입경합/ACK/전체rollback. 선언취소·재개는미정이고과거예약자동복구를만들지않는다.
- 다중레이드묶음/방병합·묶음한도/공통참가·전체탈퇴/부분완료. 하위A완료로미완료B/C까지전체탈퇴하는정책은미확정이다. 동일레이드재도전타임과다른레이드묶음을합치지않는다.
- 역할별전투력판정근거, 그룹공개범위왕복/연결그룹·기존외부인/신청유지·변경권한은미완료대조대상이다.

위는새질문일괄게시나정책확정이아니다. 우선Backend가관계도/명령흐름·최소DTO·대안/위험을작성하고꼭필요한결정만대조한다.
