## 정책과 데이터 책임

공용 time_policy.interval과 scheduling.set_times에 기본false의minute_precision 옵션을 추가했다. 기본경계는5분,명시적베타경로만UTC offset0/초·마이크로초0의정수분을선택한다. 시작/끝을반올림하지않고양의구간/최대24시간·진행시간5분배수·주차/점검·저장된출발하한·현재시각검사는유지한다.

생성context/POST와현재·다음주개방은같은beta_schedule.config/install을재사용한다. 실제공유경로를수정해설치/set_times에도옵션을전달했고기존최종기한검사를유지했다. 동시에C/N을만들어도각각의원분을보존하며한번의트랜잭션/실패롤백/기존명령ACK를유지한다.

제안create/evaluate에서는현재주차/세대의BetaSchedule이존재하고그session_id가제안대상과같을때만분정밀도를사용한다. 프로필만베타라고구세션을완화하지않는다. 수락/재평가/검토복구가같은evaluate를재사용하므로저장된제안이후5분검사로거절되는불일치를막는다. 1인은별도명시수락·다인은기존투표정책/CAS/소유·자격/동의/예약을유지한다. 비활성IF-001주차재개경로는변경하지않았다.

자동조율ceil_tick/TICK은5분이며복사표coverage·타예약중복제외·자기약속정확제외·기본출발보다이른후보정책을유지한다. 기본확정의명시시각만분정밀도를사용하고early_confirmed의시간배치는기본5분검사로남겼다. 18:03의기본기한/가입마감은정확히17:33이고,기한당시확정/출발후검토우선순위·지연확정롤백도유지한다.

개인표밖생성·직접제안·본인수락을허용하되기존유효표복사/자격검사는유지한다. 수동타예약겹침을새일괄거절로바꾸지않았다. 예약의timestamp/segment/동의·해제이력과명시시각을보존한다. DB필드·migration/자료변환/삭제·이중운영/보정경로는없다.
