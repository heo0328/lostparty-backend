## 검증 사례의 정확한 상태

아래는 **요청된 기대 결과/앞으로 작성할 검증 기준**이다. 이번 베타 기능의 통과 결과나 기존 격리시험 수로 표시하지 않는다.

- 목 생성·토18기본·추가2명·리더포함3명/금20공통이면 금20확정. 조기후보없으면 토18유지. 토17:30기한에 인원미달/리더단독이어도 기본확정. 이미조기확정이면 원기한/개인표변경으로 이동 없음.
- 기한정각·지연·중복 worker,가입/승인/탈퇴/표갱신 경합,마감 후 신규증가 차단·최초임계합류예외,예약 중복생성/원ACK재송·C/N/종료/해산 격리.
- 전체미설정/부분구간/조회실패 구분·pending자동공급없음·실제가입/표복사원자성·다른예약/점검·진행시간 보존·확정약속 임의이동없음.
- 동시발급/원키재송 추가발급없음·C/N별도·N→C불변·선행0·비참가자/pending/반대T참가자의 표시2값 누출없음.
- 메모없음/20자/초과·저장0~5/위조6개,본인권한/공개누출·기기간동시수정·프리셋변경후옛신청불변·원본문재송/중복신청방지.

20자 단위는 사용자 인지 문자/단일행·trim·빈내용=메모없음이 Flutter 추천이다. emoji/조합문자·줄바꿈/제어문자와 정확 규칙은 아직 닫힌 wire가 아니다. Python len을 곧바로 확정 규칙으로 쓰지 않는다. 자동조율 OFF 기본값도 고정 설계에서 제안값으로 구분돼 있어 계약 제안에 명시해야 한다.
