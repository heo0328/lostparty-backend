# 계약 예시·기준 시점 자료

이동 전 JSON 바이트와 내부 $id·버전·상태·역사적 경로를 보존했다. 파일명이 기능 중심으로 바뀌어도 새 계약 합의나 API 변경을 뜻하지 않는다. 설계 snapshot과 합성 응답·성능/실행 보고의 확인 범위를 구분한다. 현재 wire는 실행 OpenAPI가 원본이다. 이 묶음은 0.4.1 고정 합의의 전체/입력core·예시·경로map이며 최신 API 전체가 아니다. 재현성과 기존 테스트 의존 때문에 파일 내용을 쪼개거나 재생성하지 않았다.
